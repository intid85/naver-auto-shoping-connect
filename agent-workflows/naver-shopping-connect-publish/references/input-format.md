# 입력 자료 형식

```text
날짜 폴더/
└─ 01_상품명/
   ├─ 원고 텍스트 파일
   ├─ 참고글.txt
   └─ photos/
      ├─ 01.jpg
      ├─ 02.jpg
      └─ ...
```

사진 파일명 순서와 원고 안 사진 슬롯 순서가 대응해야 한다.

`참고글.txt`에서 파서가 인식하는 핵심 형식:

```text
제품: 상품명
쇼핑커넥트: id 123456789
발급링크: https://...
단축링크: https://...
```

- `제품`은 쇼핑커넥트 검색어로 우선 사용한다.
- 상품 ID와 링크는 기존 발급 정보를 식별하는 메타데이터다.
- 원시 링크 문자열은 본문에 표시하지 않는다.
- 내부 사진 자리표시자는 최종 글에 남아서는 안 된다.

필수 고지 문구:

`이 포스팅은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.`
