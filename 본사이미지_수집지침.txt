쇼핑커넥트 본사 이미지 수집 지침 (모든 글쓰기 에이전트용)
════════════════════════════════════════════════════════════

[목적]
네이버 쇼핑커넥트 상품의 "본사 제공 이미지"를 받아
블로그 글(photos/)에 쓰기 위한 방법. 저작권 안전 + 커넥트 연동에 최적.

[핵심 원칙]
- 쇼핑커넥트 발급링크의 상세정보에 있는 이미지 = 본사가 제공한 공식 이미지
- 남의 리뷰 사진 / 개인 블로거 실내 사진 절대 쓰지 말 것 (저작권 위험 + 저품질)
- 받은 이미지는 고해상도(20KB 이상)인지 확인

────────────────────────────────────────
1. 상품 페이지 접근 (네이버 로그인 필수)
────────────────────────────────────────
URL 형태:
  https://brandconnect.naver.com/{계정ID}/affiliate/products/{상품ID}
  예: https://brandconnect.naver.com/993045947072320/affiliate/products/890458848691936

- 브랜드커넥트는 네이버 로그인 필요
- 로그인 쿠키(naver-state.json)로 접근
- 접근하면 "상품 정보 / 발급링크 관리" 화면이 뜸

────────────────────────────────────────
2. 상세정보 이미지 위치
────────────────────────────────────────
- 페이지 아래로 스크롤하면 "상세 정보" 영역이 나옴
- 여기 있는 제품 이미지들이 본사 제공 컷
- 이미지 src는 shop-phinf.pstatic.net 원본으로 노출됨

실제 원본 URL 예시 (dthumb 프록시 안에 숨겨져 있음):
  https://shop-phinf.pstatic.net/20241210_197/17338088452097aAgJ_JPEG/58286065161033892_924985475.jpg
  (dthumb-phinf.pstatic.net?src="...shop-phinf..." → 안의 src 값이 진짜 원본)

────────────────────────────────────────
3. 원본 이미지 다운로드 방법
────────────────────────────────────────
1) 상품 페이지에서 img 태그의 src 수집
   - dthumb-phinf 주소가 나오면, 그 안의 src="https://shop-phinf..." 부분이 진짜 원본
   - 또는 shop-phinf.pstatic.net 직접 접근

2) 원본 URL 다운로드 (Referer 붙이기):
   User-Agent: Mozilla/5.0...
   Referer: https://brandconnect.naver.com/
   
   shop-phinf.pstatic.net 은 로그인 없이도 Referer 있으면 받아짐

3) 저장 규칙:
   - photos/01.jpg, 02.jpg ... 번호 순서로
   - 고해상도(20KB 이상)만 사용
   - 정면 / 사선 / 디테일 / 세트·라이프스타일 각도로 4~5장

────────────────────────────────────────
4. 블로그 글과 사진 개수 맞추기
────────────────────────────────────────
- 붙여넣기본문.txt 의 "빈 줄 2개" 구간(사진슬롯) 개수 = 사진 장수
- 사진 4장이면 슬롯도 정확히 4곳
- 안 맞으면 사진이 글 끝에 몰리거나 빈 칸 생김

────────────────────────────────────────
5. 금지 사항
────────────────────────────────────────
- X 가격·커넥트 UI 캡처 (이미지로 넣지 말 것)
- X 블로거 얼굴/실내 무단 복제
- X 남의 리뷰 사진 (AI로 조작해도 저작권은 원본 소유자 것)
- X 20KB 미만 저화질
- X 본사 이미지라도 과장 홍보 문구 붙이지 말 것

[완료 기준]
- 쇼핑커넥트 상세에서 본사 이미지 4~5장 받아 photos/에 저장
- 각 파일 고해상도 확인
- 본문 사진슬롯 개수와 일치

이상. 이 지침은 한성(사장님) 네이버 블로그 자동화 워크플로우에 사용.
